# Checklist Demo ELO E2E

Use este checklist antes e durante qualquer apresentacao do ELO E2E TEST. A demonstracao e controlada, ficticia e nao representa producao.

## Antes de abrir a tela

- [ ] Usar aba anonima ou navegador limpo.
- [ ] Confirmar que o projeto e exatamente `mplpzyalcxhhinuvjthx`.
- [ ] Confirmar que o projeto `lidueokjpzxdybtongbk` nao sera usado.
- [ ] Usar apenas usuario ficticio com dominio `.test`.
- [ ] Nao usar conta pessoal, municipal, de cliente ou de prefeitura real.
- [ ] Confirmar que nao ha chave, token, JWT, senha ou service role visivel no frontend.
- [ ] Confirmar que nenhum dado real sera usado ou digitado.
- [ ] Confirmar WhatsApp desligado.
- [ ] Confirmar e-mail desligado.
- [ ] Confirmar que a apresentacao nao sera declarada como producao.

## Durante a apresentacao

- [ ] Nao executar SQL.
- [ ] Nao executar Supabase CLI.
- [ ] Nao executar cleanup.
- [ ] Nao executar seed/setup.
- [ ] Nao executar `supabase login`.
- [ ] Nao executar `supabase link`.
- [ ] Nao criar instituicao.
- [ ] Nao excluir instituicao.
- [ ] Nao criar usuario de aplicacao.
- [ ] Nao alterar permissoes.
- [ ] Nao enviar mensagens externas.
- [ ] Nao acionar WhatsApp.
- [ ] Nao acionar e-mail.
- [ ] Nao demonstrar dados reais.
- [ ] Nao apresentar como ambiente definitivo.

## Dados permitidos

- [ ] Instituicao ficticia E2E.
- [ ] Unidade ficticia E2E.
- [ ] Gestor ficticio E2E.
- [ ] Usuario leitura ficticio E2E.
- [ ] Estoque ficticio E2E.
- [ ] Patrimonio ficticio E2E.
- [ ] Documento ficticio E2E.
- [ ] Notificacoes `in_app` ficticias.

## Roteiro permitido

- [ ] Login.
- [ ] Visao Geral.
- [ ] Almoxarifado.
- [ ] Patrimonio.
- [ ] Sentinela.
- [ ] Notificacoes.
- [ ] Relatorios e Acervo.
- [ ] ELO.
- [ ] Consulta offline.

## Frases de seguranca

- [ ] "Este e um ambiente E2E homologado, nao producao."
- [ ] "Os dados exibidos sao ficticios."
- [ ] "Nao ha envio externo de WhatsApp ou e-mail nesta demonstracao."
- [ ] "Nao faremos alteracoes estruturais nem SQL durante a apresentacao."

## Encerramento

- [ ] Fechar sessao ou janela anonima.
- [ ] Nao salvar senha no navegador.
- [ ] Registrar somente observacoes funcionais, sem IDs completos.
- [ ] Nao fazer commit/push como parte da demonstracao.
