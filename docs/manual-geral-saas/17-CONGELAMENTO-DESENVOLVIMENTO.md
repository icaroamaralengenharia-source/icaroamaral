DATA: 2026-08-09

STATUS: DESENVOLVIMENTO FUNCIONAL CONGELADO PARA INICIO DE PILOTO/VENDA.

## Regra

Nao iniciar novos modulos ou refatoracoes grandes ate haver:

- feedback de piloto;
- bug real reproduzido;
- necessidade comercial comprovada;
- exigencia de seguranca;
- requisito operacional real.

## Correcoes permitidas durante congelamento

- P0/P1 reais;
- seguranca;
- perda de dados;
- regressao;
- bloqueio de cliente;
- erro de PDF/documento critico.

## Nao permitido sem justificativa

- feature por ansiedade;
- novo modulo sem cliente;
- refatoracao estetica ampla;
- reescrita de arquitetura;
- reabrir CADISTA sem decisao explicita.
