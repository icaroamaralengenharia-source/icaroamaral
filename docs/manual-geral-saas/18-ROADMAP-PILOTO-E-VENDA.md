# Roadmap Piloto e Venda

## P1 - Piloto real

Conseguir primeiros usuarios, operar com acompanhamento e registrar feedback estruturado.

## P1 - Onboarding

Criar processo simples de ativacao, perfil, ambiente, dados iniciais e treinamento rapido.

## P1 - Monitoramento

Implantar logs, erros, disponibilidade, rotas criticas e alertas operacionais.

## P1 - Backup do banco

Fechar Supabase/PITR/export, rotina de restauracao e plano de desastre.

## P1 - Seguranca

Auditar vulnerabilidades npm, dependencias, secrets, roles, RLS e acesso externo.

## P2 - RDO -> analise tecnica composta

Encadear RDO e triagem tecnica quando houver contexto suficiente, sem inventar fatos.

## P2 - Rastreabilidade de fontes internas

Conectar respostas a documentos, RDOs, orcamentos, ensaios e registros internos.

## P2 - BM + RDO + contrato + ensaio

Criar leitura integrada para medicao, execucao, contrato e evidencias tecnicas.

## P3 - Hunter

Evoluir de MVP interno para produto apenas se houver demanda real e fonte confiavel.

## CADISTA

Continuar congelado ate decisao explicita de retomada.
