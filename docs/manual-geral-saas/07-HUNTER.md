# Manual Hunter

Status: MVP / uso interno.
Classificacao: PARCIAL.
Superficie verificada: Noticias, aba Hunter Licitacoes / dados em noticias/dados/licitacoes.json.

## Para que serve

Hunter apoia a leitura de licitacoes e oportunidades publicas, com foco em consulta e triagem inicial. A documentacao de Noticias indica uso de API publica PNCP sem autenticacao e sem escrita para Hunter Licitacoes.

## Uso seguro

1. Abrir a area de Noticias/Hunter Licitacoes.
2. Filtrar por termo, estado, modalidade ou prazo quando disponivel.
3. Abrir sempre a licitacao oficial na fonte.
4. Validar objeto, prazo, edital, anexos e requisitos fora do sistema antes de qualquer decisao comercial.

## O que nao prometer

Hunter nao esta pronto como servico autonomo de venda. Nao prometer cobertura completa de portais, captura garantida, leitura integral de edital, ranking automatico definitivo ou alerta juridicamente suficiente.
