# Escopo do piloto

## Incluído

- um usuário principal;
- uma obra inicial;
- ELO Web/App conforme disponibilidade;
- Stock;
- RDO;
- relatórios;
- vistoria;
- anexos;
- memória explícita.

## Não incluído automaticamente

- customização ilimitada;
- integração ERP;
- suporte 24 horas;
- novas features sob demanda;
- migração massiva de dados;
- criação de dados em produção para a demonstração.
