# Critérios observáveis de sucesso

Durante o piloto, registrar evidência simples para cada item:

- o usuário acessa a obra correta;
- consulta estoque e identifica o saldo de cimento;
- cria ou consulta um RDO;
- abre o PDF ou usa corretamente o plano B;
- executa uma vistoria com conformidade e não conformidade;
- envia e localiza um arquivo;
- gera relatório a partir da análise;
- salva e recupera uma memória explícita;
- entende o fluxo sem assistência constante;
- o tempo real de cada etapa é medido durante o uso.

Não inventar percentual de economia antes de medir o piloto real.
