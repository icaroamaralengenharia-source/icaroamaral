# Feedback pós-demo

Fazer somente estas perguntas na primeira conversa:

1. Qual parte pareceu mais útil?
2. O que hoje você faz manualmente?
3. Qual etapa mais consome tempo?
4. Você usaria isso em uma obra real?
5. O que impediria você de usar amanhã?
6. Quem mais da equipe precisaria acessar?

Registrar respostas e exemplos concretos; não aplicar questionário longo durante a demonstração.
