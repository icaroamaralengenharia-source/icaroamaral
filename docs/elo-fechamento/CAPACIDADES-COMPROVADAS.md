# Capacidades comprovadas

## Conversacional

- Conversa geral e acolhimento básico.
- Contextualização de perguntas técnicas.
- Tratamento de prompts mistos com linguagem humana e técnica.

## Engenharia

- Triagem preliminar de patologias: fissura, trinca, rachadura, destacamento, eflorescência, infiltração e sintomas correlatos.
- Fiscalização técnica e notificações de não conformidade.
- Pavimentação: CBUQ, exsudação, afundamento e trilhas de roda.
- Quantitativos/orçamento quando há premissas suficientes.
- Uso de SINAPI/ORSE quando base disponível, sem inventar base ausente.

## Documentos

- Leitura de PDF como documento, sem confundir com geração de PDF de orçamento.
- Geração validada de PDFs suportados.
- Relatório/notificação técnica com linguagem prudente.

## Operação

- RDO operacional e contexto de obra.
- Integração com fluxos existentes de Stock/Patrimônio conforme dados disponíveis.
- Preservação de RDO simples sem roubo por patologia.

## Visual

- Ponte de imagem estruturada.
- Fallback sanitizado quando a IA visual ou rede não estão disponíveis.

## Routing

- CADISTA x objeto técnico.
- Patologia x orçamento.
- RDO x fiscalização.
- Relatório genérico x não conformidade.
- Conceitos legítimos x fiscalização documental.
