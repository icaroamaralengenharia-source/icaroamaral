# Roadmap curto

## P1 - RDO -> análise técnica composta

Permitir ler RDO, extrair ocorrência, encaminhar conteúdo para triagem técnica e responder mantendo rastreabilidade da origem.

## P1 - Rastreabilidade de fontes internas

A resposta deve indicar de onde veio cada dado: RDO, contrato, BM, ensaio, SINAPI/ORSE, projeto ou documento anexado.

## P1 - Integração medição/contrato

Cruzar BM + RDO + contrato + ensaio para apoiar fiscalização técnica com premissas rastreáveis.

## P2 - Qualidade dos 61 PASS_COM_RESSALVA

Analisar por clusters de ressalva, sem caçar regex caso a caso.

## P2 - PDF QA visual

Automatizar screenshots, comparação visual e inspeção de layout para os PDFs gerados.

## P2 - Memória da obra

Melhorar contexto persistente por obra/empresa quando tecnicamente seguro e auditável.
