# Limitações reais

1. Fluxo composto RDO -> análise técnica ainda não é encadeado automaticamente.
2. 61/200 cenários tiveram ressalvas de qualidade.
3. O ELO continua sendo assistente, não substituto de responsável técnico.
4. Dados, leis, normas e preços externos dependem de fonte disponível.
5. O ELO não deve inventar norma quando fonte não existir.
6. Algumas integrações dependem de backend, internet, chaves e permissões.
7. Inspeção visual manual integral dos PDFs deve ser complementada quando o ambiente permitir.
8. O piloto deve manter revisão humana, especialmente para contratos, notificações, laudos, custos e decisões de campo.
